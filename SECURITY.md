# Security

Please report a vulnerability in this code privately, by email to
security@pchy.app, not in a public issue or change.

Include what you found, how to reproduce it, and what an attacker gains. We
will acknowledge the report, keep you informed while we fix it, and credit you
when the fix is public unless you ask us not to. Our disclosure policy is at
https://pchy.app/security.

If you run a bot built from this code and its store or store key may have
leaked, reset the bot's keys in Peachy: Settings › Organizations and bots ›
your bot › Link a new server (on Mac, You › Organizations and bots).
